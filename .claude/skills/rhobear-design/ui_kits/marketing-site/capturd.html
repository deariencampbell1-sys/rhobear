How it works

Feed it a map. Walk away.

No clicking through pages by hand, no model deciding what to shoot. You hand RHOBEAR Captur'd the routes and states you care about, and it walks every one the same way every time.

01

Hand it the map

Give it your site map and the states that matter, like default, hover, dark mode. It queues every page.

02

A swarm of captors runs

Captors work in parallel, so a big site finishes in one pass instead of one page at a time. The grid fills as they land.

03

Clean frames rest on disk

Every page and state lands as a clean, named screenshot. Same input, same output, no flaky reruns.

04

Pour into Remotion

The frames feed straight into Remotion. Cut hundreds of product videos from one capture run, for a cost that rounds to nothing.

Not AI · on purpose

It doesn't think. It captures.

RHOBEAR Captur'd is a deterministic tool, not a model. That's the whole reason it's cheap. There's no reasoning to pay for, no token meter spinning while it works. It's the picture-taker for whatever Designs just made: point it at your apps, and it soaks them in.

MAP-DRIVEN

You hand it the route list

No model guesses what to shoot. It captures exactly the pages and states you named, in order.

PARALLEL

A swarm, not a single screenshot

Captors run side by side. A site that would take an afternoon of manual grabs fills in while you start the next build.

REPEATABLE

Same run, same frames

Deterministic means the run you do tonight matches the run you do next month. No AI drift between captures.

No model means no model bill. Run it as often as you ship.

FAQ

Honest answers to the obvious questions.

Anything not here, the source is right there to read.

Is it AI?

No, and that's the point. RHOBEAR Captur'd is a deterministic capture tool built on Playwright. No model, no token meter, no guessing what to shoot.

What does a run cost?

Machine time, and that's it. Run it on your own box or a tiny VPS. There's no per-shot price and no model invoice behind it.

What can it capture?

Every page and every state you put in the map, like default, hover, dark mode, logged-in. It walks them all in one pass.

Does it really feed video?

Yes. The clean frames pour straight into Remotion, so one capture run can cut hundreds of product videos for next to nothing.

Why a swarm?

Captors run in parallel, so a big site finishes in one pass instead of page by page. You point it and walk away.

Do I own it?

It's MIT. Clone it, fork it, wire it into your own pipeline, ship it inside your own product. No account, no lock-in.
