What it does

A senior reviewer on every pull request.

No new dashboard to learn, no webhook to wire. It lives in the PR thread where your code already does — reads the change, reads the repo around it, and posts a verdict your team can act on.

A binary verdict, every time

ACCEPT, FIX-FORWARD, or BOUNCE — posted as a real PR review your team can resolve, not a wall of nitpicks nobody reads.

File:line evidence + a fix

Every finding lands on the exact line, with a severity and a one-line fix — security, correctness, scope creep, missing tests, broken contracts.

Reads your whole codebase

On install it maps every file, function, and call site — so a 12-line PR can surface the bug in the caller it just broke, not only what's in the diff.

Auto-fix builds

When you want it to stop flagging and start shipping, it opens the patch as a PR. Builds are the metered unit — reviews stay unlimited.

Adversarial verify

Every finding is re-checked before it posts and re-verified when you push a fix — so false positives get dropped, not dumped on your team.

Your code stays yours

Inference-only. No diff retained past the review, never trained on, never sold. It runs on our own infra, not a SaaS middleman.

FAQ

Honest answers to the obvious questions.

The stuff every team asks before they install a bot on their repos.

Is it really free?

Yes — one full review every day, forever, no card. Install the GitHub App and mention @rhobear-reviews on a PR. Paid tiers unlock unlimited reviews and auto-fix builds.

What do I actually pay for?

Auto-fix builds — where the reviewer stops flagging and opens the patch as a PR. Reviews stay unlimited on every paid tier. You're metered on fixes, never on seats.

How is it different from CodeRabbit?

It reads your whole codebase, not just the diff, and posts one binary verdict — ACCEPT, FIX-FORWARD, or BOUNCE — instead of a wall of nitpicks. And it charges per fix, not $24 per seat every month.

Does my code get trained on?

Never. Inference-only. The diff isn't retained past the review, never trained on, never sold. It runs on our own infra, not a SaaS middleman.

How fast is a review?

A binary verdict with file:line evidence in under two minutes — about half of CodeRabbit's time to first comment. Every finding is adversarially re-checked before it posts.

Where does it sit in the workflow?

In the PR thread where your code already lives — no new dashboard to learn, no webhook to wire. The dashboard at reviews.rhobear.ai is where it all adds up.
